# AI-GROWTH-WORKSPACE Known Problems

Use this file for defects and operational problems that are confirmed or
credible enough to track. Implementation work belongs in a ticket.

## Rules

- Give each problem a stable BUG ID.
- Label the report OBSERVED, OWNER-STATED, RESEARCHED, ASSUMPTION, or UNKNOWN.
- Record the affected workflow and current evidence.
- Distinguish symptom, likely cause, and confirmed root cause.
- Link the repair ticket under `tickets/`.
- Keep a safe workaround when one exists.
- Close the problem only after acceptance and provider or system-of-record
  readback for any external effect.
