# AI-GROWTH-WORKSPACE Memory

This file holds compact, durable project facts that should survive across
sessions. It is not a transcript, task log, or substitute for current evidence.

## Rules

- Record only facts, preferences, constraints, and accepted operating patterns
  likely to matter again.
- Give every fact a date, evidence label, and source.
- Prefer provider or system-of-record readback and current project files.
- Keep assumptions and unknowns explicit.
- Put active work in tickets, current state in `STATUS.md`, decisions in
  `DECISIONS.md`, and defects in `BUGS.md`.
- Replace a stale fact by adding a dated correction; do not erase useful
  history without explanation.
- Do not store credentials or unredacted confidential records.

`RECOMMENDATION` is a proposed action, not evidence.
