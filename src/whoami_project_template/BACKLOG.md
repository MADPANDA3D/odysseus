# AI-GROWTH-WORKSPACE Backlog

The backlog holds useful work that is not part of the current verified stage.
An item here is not a commitment, purchase approval, or implementation ticket.

## Triage rules

- Capture the idea in one sentence.
- Connect it to a business outcome.
- State the evidence that would make it worth doing.
- Prefer finishing the active stage before promoting another item.
- Create a ticket only when the owner chooses the item for implementation.
- Put a chosen but unclaimed ticket in `tickets/open/`.
- Remove duplicates; preserve the clearest version.
- Treat recommendations as proposals, not evidence of need.
