AI-GROWTH-WORKSPACE TICKETS - BLOCKED

This folder holds work that cannot make meaningful progress until a named
dependency or owner action changes.

A difficult task is not automatically blocked.

REQUIRED BLOCKER RECORD

Every blocked ticket must record:

- completed work so far;
- current safe state;
- exact blocker;
- blocker owner;
- evidence that the blocker is real;
- exact unblock condition;
- action needed from the owner or provider;
- last checked date;
- next review date; and
- what can still proceed without crossing the blocker.

When the unblock condition is met, move the ticket back to in-progress/ and
record the new evidence. If the requested outcome is abandoned, close the
ticket under skipped/ with the owner decision rather than leaving it
indefinitely active.
