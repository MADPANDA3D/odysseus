AI-GROWTH-WORKSPACE TICKETS - COMPLETED

This folder holds finished tickets whose acceptance condition passed and whose
external result, if any, was confirmed by provider or system-of-record readback.

REQUIRED CLOSEOUT

Every completed ticket must record:

- exact outcome;
- completion date;
- acceptance test;
- provider or system-of-record readback for external outcomes;
- evidence link;
- final system or file state;
- remaining limitation or risk;
- rollback or recovery status; and
- follow-up ticket, if needed.

A successful local command, generated file, or agent statement is not proof of
an external outcome. Completion requires the promised result and evidence.

REOPENING

Do not rewrite a completed ticket into new work. Create a new ticket, reference
the completed ticket, and explain what changed.
