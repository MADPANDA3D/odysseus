AI-GROWTH-WORKSPACE TICKETS - IN PROGRESS

This folder holds work that has been accepted for action and is not yet in a
final state.

Move approved work from open/ to this folder only when an owner or agent is
ready to act. Keep one active implementation ticket at a time.

ADMISSION CHECK

A ticket belongs here only when it has:

- a stable ticket ID and clear title;
- a business reason;
- an exact permitted target;
- excluded scope;
- an owner;
- acceptance evidence;
- any required approval;
- a rollback or safe-stop path; and
- one current next action.

WHILE ACTIVE

Update the same ticket after each meaningful step:

- observation;
- action;
- result;
- evidence link;
- state;
- next action.

Do not create a second active ticket for the same target and outcome. Link
related work instead.

EXIT

Move the ticket to:

- completed/ when acceptance and provider or system-of-record readback pass;
- failed/ when work stops without meeting acceptance;
- blocked/ when a named dependency or owner action prevents progress;
- skipped/ when the owner deliberately declines or defers the work.

Before moving it, make sure STATUS.md and HANDOVER.md point to the same final
state.
