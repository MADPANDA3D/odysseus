AI-GROWTH-WORKSPACE TICKETS - OPEN

This folder holds approved work that is ready to be claimed but is not active.

An open ticket must include:

- stable ticket ID and clear title;
- project outcome and reason;
- exact target and excluded scope;
- owner;
- acceptance evidence;
- approval boundary;
- recovery or safe-stop requirement; and
- dependencies.

Move one ticket at a time to in-progress/ when an owner or agent is ready to
act. Leave unapproved ideas in BACKLOG.md.
