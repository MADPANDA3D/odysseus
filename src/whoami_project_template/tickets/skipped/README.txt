AI-GROWTH-WORKSPACE TICKETS - SKIPPED

This folder holds work the owner deliberately declined or deferred after
review.

Every skipped ticket must record:

- decision date;
- owner;
- reason;
- current safe state;
- evidence reviewed;
- effect of not doing the work;
- revisit trigger, if any; and
- related decision ID.

Skipped is a truthful final state, not a failure. If the work becomes relevant
later, create a new open ticket and reference the skipped record.
