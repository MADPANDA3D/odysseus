AI-GROWTH-WORKSPACE TICKETS - FAILED

This folder holds work that stopped without meeting its acceptance condition.
Failure is a usable result when it preserves evidence and a safe state.

REQUIRED FAILURE RECORD

Every failed ticket must record:

- expected result;
- last action attempted;
- OBSERVED result or error;
- evidence link;
- likely cause, labeled OBSERVED or ASSUMPTION;
- current safe state;
- whether rollback occurred;
- effect on other workflows;
- owner decision; and
- smallest sensible retry or alternate path.

Do not erase a failed ticket after a later success. Create or continue the
appropriate ticket and preserve the failed record as evidence.

Use blocked/ instead when work can continue only after a named external
dependency, approval, credential, provider, purchase, or owner action changes.
