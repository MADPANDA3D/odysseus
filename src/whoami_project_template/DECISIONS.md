# AI-GROWTH-WORKSPACE Decision Log

Record accepted choices here so later sessions understand what was decided,
why it was chosen, and what evidence could justify changing it.

## Rules

- Append new decisions; do not silently rewrite history.
- Use one stable decision ID per choice.
- Distinguish accepted decisions from assumptions.
- Use OBSERVED, OWNER-STATED, RESEARCHED, ASSUMPTION, and UNKNOWN consistently.
- Treat RECOMMENDATION as a proposed action, not evidence.
- Link evidence when the decision depends on measured behavior.
- If a decision changes, add a new entry and reference the prior ID.
- Put unapproved ideas in `BACKLOG.md`.
